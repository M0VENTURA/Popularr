{# MusicBrainz Release Search — Modal Wrapper. Wraps components/_musicbrainz_search_component.html in a Bootstrap modal. INCLUDED ONCE, GLOBALLY, BY base.html (into #global-mb-search-container). Do NOT include it from a page as well: the component renders fixed ids (mbSearchArtist, mbSearchResults, mbSelectedRelease, …) and performMbSearch() resolves them with document.getElementById, which returns the FIRST match in DOM order. A second copy on the page would mean the search writes its results into whichever copy happens to be earlier while the visible one sits empty. Pages that want inline (non-modal) search should include components/_musicbrainz_search_component.html directly, which is exactly what that component's own header says. No JavaScript, no handlers — a pure wrapper, so this is a like-for-like port. #}
