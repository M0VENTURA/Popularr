{# Unified MusicBrainz Release Search Component ============================================= Renders the 4-field search form, the filter bar, the results grid and the "selected release" panel. INCLUDE THIS ONCE PER PAGE. -------------------------------------------- Every element below has a FIXED id (mbSearchArtist, mbSearchResults, mbSelectedRelease, …). The search functions resolve them with `document.getElementById(...)`, which returns the FIRST match in DOM order. Including this component twice therefore produces duplicate ids, and the search writes its results into whichever copy happens to come first in the document — usually the hidden global modal in base.html — while the copy the user is looking at keeps showing the empty placeholder. That is the "the modal opens but nothing ever appears" symptom. base.html already includes this component (via components/_musicbrainz_search_modal.html) on EVERY page, so: * To open the shared modal, call `openGlobalMbSearch(artist, album, cb)` — do NOT include this file again. * Only include this file directly on a page that wants the search form rendered INLINE, and only if that page does not also rely on the global modal.
