It could not express the fields the album page can, so editing an album from the artist page offered strictly less than editing it from the album page — for the SAME endpoint. 2. The values were only ever filled from ``data-*`` attributes on the release row, and the MBID box was never read back on save at all, so the fields appeared not to save. The field NAMES below are the exact ones ``routes/ui_routes.py::album_detail`` reads on POST, and the values are loaded per-album from ``GET /api/album/metadata`` — the same precedence the album page uses.
