API Keys & Integrations
(recommended before first scan)

Configure external providers used during popularity, singles, and metadata scans. Services with an API key are enabled automatically when a key is entered.

Last.fm Popularity & Recommendations
Primary listener/playcount source for popularity scoring (last.fm/api/account/create). Username enables personalized recommendations.
ListenBrainz Popularity & Weekly Playlists
Used for ListenBrainz popularity scoring and personalized playlists (listenbrainz.org/settings).
Discogs Singles & Genres
Powers single/EP release confirmation, official video detection, and release genres (discogs.com/settings/developers).
MusicBrainz
No API key required. Powers MBID resolution, singles & cover detection, and release lookups.
TheAudioDB (optional)
Fetches artist/album metadata and genre tags (theaudiodb.com).
Soulseek (slskd) (optional)
Web URL and API key for P2P music downloads.
Google Gemini (optional)
Used only to generate AI cover art for Top Genre playlists.
