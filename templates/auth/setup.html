Welcome to Popularr

Let's get you set up in a few steps

1
Connect to Navidrome
(required)

Popularr reads your library from Navidrome and sends star ratings back. Your password is stored in config.yaml only.

Full URL including the scheme — no trailing slash required. Example: https://music.yourdomain.com
PostgreSQL Database (pre-filled from environment)
2
API Keys
(optional — skip if unsure)

Enable popularity scoring and recommendations. You can add these later from Config.

Last.fm
Get your API account at last.fm/api/account/create
Discogs
Generate a token at discogs.com/settings/developers
ListenBrainz
Get your token from listenbrainz.org/settings
Soulseek (slskd)
slskd is a modern Soulseek client. Provide its web UI URL and API key for downloading music.
3
Mood & Genre Analysis
(optional — off by default)

Essentia runs ML models locally to detect mood and genre tags. Downloads ~87 MB of model files.

4
File Management
(optional — sensible defaults provided)

How files are organized into your music library when downloaded or renamed. You can change this later in Settings → File Management.

{track_number} — 2-digit track number
{album_artist} — album artist name
{artist} — track artist name
{title} — track title
{album} — album title
{year} — release year
File Conversion
FLAC files are converted to MP3 when imported or renamed. Metadata and cover art are carried over during conversion.
5
Automation & Extras
(recommended defaults — change anytime in Config)

Popularr runs several background jobs automatically. Switch them on or off now — everything here can be changed later from Config → Automation Services.

Background Services
Automatically import newly detected songs from Navidrome.
Score popularity for tracks automatically after each import.
Monitor the downloads folder and process completed files automatically.
Flag cover songs during scans (uses MusicBrainz lookups).
Daily Wikipedia + weekly MusicBrainz scan for new releases of your artists.
Scan Outputs & Extras
Generate "{artist} - Essential Collection.m3u" playlists from 4★/5★ tracks.
Generate "{genre} - Top Tracks.m3u" playlists across the whole library.
Rolling "New Music.m3u" of your most recently added 4★/5★ tracks — created once 100 qualify, newest additions push older ones out.
Embed ratings, genres and cover art into your audio files. Turn off for a read-only library.
Push star ratings to every Navidrome user after each scan (not just the primary user).
Only accept FLAC / 320 kbps MP3 downloads and reject lower-quality matches.
